أبوظبي العالمي للأسواق المالية (ADGM) — جزيرة المريّة

نبذة عن الوظيفة

نبحث عن مهندس DevOps محترف للانضمام إلى فريق التقنية لدينا في أبوظبي. ستتولى تصميم وتشغيل بنية تحتية سحابية متقدمة على AWS، وإدارة عناقيد Kubernetes، وأتمتة خطوط CI/CD، وضمان موثوقية الأنظمة وملاحظتها. المرشح المثالي لديه شغف بالأتمتة، وفهم عميق لـ Infrastructure as Code، وقدرة على حل المشكلات في بيئة إنتاجية ذات ضغط عالٍ.

المسؤوليات الرئيسية

  • تصميم وتشغيل البنية التحتية السحابية على AWS (EKS, EC2, S3, RDS, IAM).
  • إدارة عناقيد Kubernetes على EKS ونشر الأعباء باستخدام Helm و ArgoCD.
  • بناء وصيانة خطوط CI/CD عبر GitHub Actions لضمان تسليم سريع وموثوق.
  • تطبيق Infrastructure as Code باستخدام Terraform و Ansible.
  • إعداد أنظمة المراقبة والملاحظة (Prometheus, Grafana, Loki, OpenTelemetry).
  • الاستجابة لحوادث الإنتاج وإجراء تحليلات ما بعد الحوادث (Blameless Postmortems).
  • تحسين أداء النظام وتكاليف البنية التحتية وتطبيق أفضل ممارسات الأمان.
  • التعاون مع فرق التطوير لتحسين تجربة المطورين (Developer Experience).

المتطلبات والمؤهلات

  • 3+ سنوات خبرة عملية في DevOps أو SRE أو Platform Engineering.
  • بكالوريوس في علوم الحاسوب أو هندسة الحاسوب أو مجال ذي صلة.
  • خبرة عملية مثبتة في AWS و Kubernetes في بيئات إنتاجية.
  • إتقان Terraform و Ansible لكتابة وحدات IaC قابلة لإعادة الاستخدام.
  • معرفة عميقة بنظام Linux والشبكات وأمن البنية التحتية.
  • خبرة في إعداد المراقبة والتنبيهات (Prometheus & Grafana).
  • مهارات تواصل ممتازة باللغتين العربية والإنجليزية كتابةً وتحدثًا.

المهارات التقنية

Kubernetes Docker AWS Terraform Ansible Linux Prometheus Grafana GitHub Actions ArgoCD Helm Python Bash Go

المزايا والمنافع

  • تأمين صحي شامل للموظف وعائلته ضمن شبكة مزوّدين معتمدين.
  • تذاكر طيران سنوية للموظف وعائلته إلى وجهة الإقامة.
  • 30 يوم إجازة مدفوعة سنويًا + إجازات رسمية وفق القانون الإماراتي.
  • مكافأة نهاية الخدمة وفق قانون تنظيم علاقات العمل في الإمارات.
  • ميزانية تطوير مهني سنوية للمؤتمرات والشهادات (AWS, CKA).
  • نموذج عمل هجين — 3 أيام في مكتب ADGM ويومين عن بُعد.

هل أنت مستعد للانضمام إلى فريقنا؟

قدّم طلبك وانضم إلى فريق تقني طموح يعمل على بنية تحتية سحابية متقدمة في قلب المركز المالي العالمي بأبوظبي. نراجع الطلبات أسبوعيًا ونعاود التواصل مع المرشحين المؤهلين خلال 5 أيام عمل.
